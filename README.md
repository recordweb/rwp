# RecordWeb Protocol (RWP)

**Editor's Draft**: https://recordweb.github.io/rwp/

**Published baseline**: https://doi.org/10.5281/zenodo.20475345

## About

This repository contains the Editor's Draft of the RecordWeb Protocol (RWP), developed by the [RecordWeb W3C Community Group](https://github.com/recordweb).

RWP is the normative protocol counterpart to the [RecordWeb Concept (RWC)](https://recordweb.github.io/rwc/).
